# Data Directory

This folder stores CSV data files generated by the Solar Panel Fault Detection system.

## Data Files

### Actual Hardware Data
- `station1.csv` - Sensor data from Solar Station 1
- `station2.csv` - Sensor data from Solar Station 2

### Simulated Data
- `simulatedstation1.csv` - Simulated sensor data from Station 1 (for testing)
- `simulatedstation2.csv` - Simulated sensor data from Station 2 (for testing)

## CSV Format

Each CSV file contains the following columns:
- **timestamp** - Data collection timestamp (ISO 8601)
- **sender_id** - Sensor/station identifier
- **voltage** - Panel voltage (V)
- **current** - Panel current (A)
- **temperature** - Ambient temperature (°C)
- **light_intensity** - Solar irradiance (W/m²)
- **humidity** - Ambient humidity (%)
- **thermistor_temp** - Temperature reading from thermistor (°C)
- **efficiency** - Panel efficiency (%)
- **relay_status** - Relay/switch status (True/False)
- **fault_type** - Detected fault classification
- **fault_index** - Numeric fault index (0-4)
- **confidence** - ML prediction confidence (0-100)
- **is_fault** - Boolean fault status
- **power** - Generated power (W)
- **recommendation** - Action recommendation for detected fault

## Notes

- CSV files are **NOT committed** to GitHub (ignored via `.gitignore`)
- This folder will be automatically created on first run
- CSV data is local to your installation and won't be shared via Git
- Use the CSV Download feature in the dashboard to export data
